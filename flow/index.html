Garage Flow / Docs

Documentation for Garage Flow, a task board that runs entirely in your browser.

Overview

Garage Flow helps you plan a project, assign work and see how far along you are. There is no account, no server and no build step. Your project state lives in a single JSON file that you can keep next to your code and commit to Git.

  • Weighted tasks: every task has a title, an assignee and a weight.
  • Three-column board: To Do, In Progress and Done.
  • Automatic progress: the completion bar is calculated from task weights.
  • Auto-save: tasks are kept in your browser between visits.
  • JSON export and import: back up, version and move your project.
  • Built-in terminal: manage tasks, read reports and handle backups from the command line.
  • Local backups: save snapshots of the board in your browser and restore them later.
  • Light and dark theme: follows your system and can be switched from the header.

Getting started

1

Create tasks in the Tasks page with a title, an assignee and a weight. Or type add "Title" @name 20 in the Terminal.

2

Move each task across the board with Start and Success as work progresses, or use start and done in the terminal.

3

Click Export JSON (or run export) to download your project state.

4

Commit the JSON file to your project repo. To view or update, import the latest JSON back into Garage Flow.

Tasks

Creating a task

Use the form at the top of the Tasks page, or the add command in the Terminal. New tasks always start in To Do.

Field Description
Task title Required. A short name for the work.
Assignee Required. The person responsible for the task.
Weight % Required. A whole number from 1 to 100: the share of the whole project this task represents.
Description Optional. A longer explanation of the work.
Due date Optional. The date the task should be finished by. Overdue tasks are highlighted in red.
Priority Optional. One of Low, Medium, High or Urgent. Defaults to Medium.
Tags Optional. A comma-separated list of labels, for example frontend, design.

The board

To Do → In Progress → Done
Column Meaning
To Do Work that has not started yet.
In Progress Work someone is doing right now.
Done Finished work. Only Done tasks count toward progress.

Moving tasks

You can move a task between columns in three ways: use the buttons on the card, drag the card and drop it on another column, or use the terminal commands start, done, back and reopen. All of them update the same status and history.

Task actions

Button Shown in What it does
Start To Do Moves the task to In Progress.
Success In Progress Marks the task as Done.
Back In Progress Returns the task to To Do.
Reopen Done Returns the task to In Progress, for example after an accidental Success.
Edit Every column Loads the task into the form. Change any field and click Save task, or Cancel to discard the changes.
Delete Every column Removes the task after you confirm. This cannot be undone.

Weights and progress

A weight describes how much of the project a task represents. The progress bar shows the weight of Done tasks compared with the weight of all tasks.

progress = done weight ÷ total weight × 100

Task Weight Status
Design 40% Done
Build 35% In Progress
Launch 25% Done

In this example the Done weights add up to 65 out of 100, so the board shows 65% complete.

Weight rules

  • Each weight is a whole number from 1 to 100.
  • The weights of all tasks should add up to at most 100%.
  • The line below the form shows how much weight is still available. In the terminal, run weights.
  • A task that needs more weight than what is left is not added, and Garage Flow tells you how much remains.
  • While you edit a task, the line shows the weight available for that task.
  • If an import pushes the total above 100%, the line turns red until you edit or delete tasks to fix it.

Progress is calculated against the real total, so the bar stays accurate even while the weights add up to less than 100%.

Auto-save

Garage Flow saves your tasks in your browser after every change, whether you make it on the board or in the terminal. Reloading the page or switching between Tasks, Terminal and Docs does not lose anything.

  • Data stays on this device and in this browser. It is not synced anywhere.
  • Another browser or browser profile starts with an empty board.
  • Clearing the site data for Garage Flow removes the saved tasks and the local backups.
  • Private or incognito windows may discard the data when they close.

Auto-save and local backups live in the same browser, so they are a convenience, not a safe copy. Export your project as JSON regularly and keep the file in your repo.

Export and import

Export JSON

The Export JSON button, or the export terminal command, downloads a file named project-status-YYYY-MM-DD.json with the current project state.

{
    "version": 1,
    "project": {
        "name": "Garage Flow",
        "updated_at": "2026-11-17T09:30:00.000Z"
    },
    "tasks": [
        {
            "id": "m3k9x2ab",
            "title": "Design the landing page",
            "assignee": "Sam",
            "weight": 40,
            "status": "done",
            "description": "Hero, pricing and footer",
            "due_date": "2026-11-20",
            "priority": "high",
            "tags": ["design", "frontend"],
            "history": {
                "created_at": "2026-11-10T08:00:00.000Z",
                "started_at": "2026-11-12T09:15:00.000Z",
                "completed_at": "2026-11-16T17:45:00.000Z",
                "reopened_at": null
            }
        }
    ]
}
Field Description
version The file format version. Currently 1.
project The project name and the time of the export.
tasks The list of tasks, each with id, title, assignee, weight and status, plus the optional fields below.
status One of todo, in_progress or done.
description Optional. The longer explanation of the task.
due_date Optional. An ISO date, for example 2026-11-20.
priority One of low, medium, high or urgent. Defaults to medium.
tags Optional. A list of short labels.
history Timestamps for the task lifecycle: created_at, started_at, completed_at and reopened_at. A value is null until the matching event happens. The terminal burndown command is built from this history.

Import JSON

The Import JSON button, or the import terminal command, loads a file you exported earlier. If the board is empty, the tasks load right away. If the board already has tasks, Garage Flow asks what to do:

Choice Result
Merge Adds the imported tasks to the board. A task with the same id is updated from the file.
Replace all Removes the current tasks and loads the ones from the file.
Cancel Leaves the board unchanged.

In the terminal the question appears as a line: answer m to merge, r to replace all, or anything else to cancel.

What Garage Flow checks

  • A file without a tasks list is rejected.
  • A file exported by a newer version of Garage Flow is rejected.
  • Older files without a version field are still accepted.
  • Files exported before the extra fields existed are accepted; missing description, due date, priority, tags and history are filled with defaults.
  • Tasks with a missing title or assignee, a weight outside 1 to 100, or a duplicate id are skipped. The message after the import tells you how many were skipped.

Terminal

The Terminal page is a command line for the same board you see on the Tasks page. Type a command and press Enter. Command names are not case-sensitive, an unknown command points you to help, and help <command> shows usage and examples for one command.

Referring to a task

Commands that act on a task accept either of these:

  • A number: #3 or 3 is the position shown in the first column of list. Numbers can shift after you delete a task, so run list again.
  • An id: the full id or the start of it, like m3k. If the start matches more than one task, Garage Flow asks you to type more characters.

Writing commands

  • Use quotes for values with spaces: add "Fix the login page" @sam 20. Single and double quotes both work, and --title="a b" works too.
  • An assignee is written as @name, or @"Sam Lee" when it has a space.
  • Options start with -- and take a value: --due 2026-11-25.
  • In add, the last number outside quotes is the weight, so add Fix login @sam 20 works without quotes.

Task commands

Command Description
add "Title" @name 20 Creates a task. Optional: --due YYYY-MM-DD, --priority low|medium|high|urgent, --tags a,b, --desc "text".
list Lists tasks. Filter with a status (todo, in_progress, done), @name, --priority p or --tag t. Alias: ls.
start <task> Moves a To Do task to In Progress.
done <task> Marks an In Progress task as Done.
back <task> Returns an In Progress task to To Do.
reopen <task> Returns a Done task to In Progress.
edit <task> --weight 30 Changes fields. Options: --title, --assignee (or @name), --weight, --due (use none to clear), --priority, --tags, --desc.
rm <task> Deletes a task after asking [y/N]. Add -y to skip the question. Alias: delete.
show <task> Shows every field of a task and its history.

start, done, back, reopen and rm accept several tasks at once, for example done 1 2 3. A command only works on tasks in the right column: done on a To Do task is skipped with a message.

Report commands

Command Description
status Progress bar and the number of tasks and weight in each column. Alias: progress.
weights Weight used and weight still available.
overdue Tasks that are past their due date and not Done.
who Work per assignee: share of the total weight and how many of their tasks are Done.
find <text> Searches title, assignee, description, due date, priority and tags.
burndown A text chart of the weight still remaining for each day, built from the task history.

The burndown starts on the earliest creation or completion date and ends today. Tasks imported without history are counted from the first day, and Done tasks without a completion date are counted as completed today.

Data commands

Command Description
export Downloads the project as a JSON file, like the Export JSON button.
import Opens a file picker. Asks merge or replace if the board is not empty.
reset Removes every task from this browser after asking [y/N]. Add -y to skip the question. Backups are kept.
backup [label] Saves a snapshot of the board. See Backups.
restore [n] Lists backups, or replaces the board with backup n.

Terminal commands

Command Description
help Shows the available commands.
clear Clears the terminal. Alias: cls.
version Shows the Garage Flow version.

Example session

> add "Design landing page" @sam 40 --priority high --due 2026-11-25
> add Build API @lee 35 --tags backend
> start 1
> done 1
> list in_progress
> status
> edit 2 --weight 30 --due none
> backup before-launch
> rm 2

The terminal and the board share the same saved tasks. A change made in one shows up in the other the next time you open that page.

Backups

A backup is a snapshot of all tasks, saved in your browser. Use it before a risky change such as an import, a reset or a big edit. Backups are managed from the Terminal.

Command Result
backup Saves a snapshot of the current board. Add an optional label: backup before-launch.
restore Lists your backups, oldest first, with their number, date, task count and label.
restore 2 Replaces the current tasks with backup 2 after asking [y/N]. Add -y to skip the question.
backup --delete 2 Deletes backup 2.
  • Garage Flow keeps the last 10 backups. Creating an 11th removes the oldest, so backup numbers can shift.
  • An empty board cannot be backed up.
  • reset and the Reset data button remove tasks but leave backups in place.
  • Restoring replaces the current tasks and cannot be undone. Run backup first if you may want them back.

Backups live in the same browser storage as your tasks. Clearing the site data removes both, so keep an exported JSON file in your repo as the real copy.

Theme

Garage Flow comes in a light and a dark theme. The first time you visit, it follows your system setting. Use the moon or sun button in the header to switch, and Garage Flow remembers your choice in this browser.

  • Until you pick a theme yourself, Garage Flow follows your system and updates when it changes.
  • The terminal and code blocks stay dark in both themes.
  • The choice is stored in this browser only, like your tasks.

Share

The Share button in the header copies the address of the current page to your clipboard and shows a confirmation.

The link opens Garage Flow, not your tasks, because tasks live in your browser. To share a project, send the exported JSON file or commit it to your repo.

Keyboard shortcuts

Keys Action
Enter Adds or saves the task while a form field is focused. In the terminal it runs the command, or sends your answer to a [y/N] question.
Esc Cancels editing a task while the form is focused, and closes a confirmation dialog.
Tab Moves to the next field or button. Use Shift + Tab to go back.

FAQ

Where is my data stored?

In your browser, on your device. Garage Flow has no server and does not send your tasks anywhere.

Can a team use Garage Flow together?

Yes, through the JSON file. One person exports and commits the file, and the others import the latest version. Use Merge to combine it with what is already on the board. There is no live sync, so the most recent import wins.

Why can I not add a task?

The weight you entered is higher than the weight still available. Check the line below the form (or run weights in the terminal), lower the weight, or free some weight by editing or deleting other tasks.

My tasks disappeared. What happened?

The site data was probably cleared, or you opened Garage Flow in a different browser, profile or private window. If you have an exported file, import it to restore the board. If you made a backup in the same browser, restore will list it.

Can I do everything from the terminal?

You can create, edit, move and delete tasks, read reports, export, import, reset and manage backups. The board adds drag and drop, search and the assignee filter.

What does the terminal ask me before deleting?

rm, reset and restore ask [y/N] and do nothing unless you answer y. Add -y to the command to skip the question.

Is there a desktop version?

Yes. Garage Flow Desktop runs this web app in a native Windows window, and Export JSON saves through the system save dialog. You can find it on the project's GitHub page.

Which browsers are supported?

Current versions of Chrome, Edge, Firefox and Safari.
